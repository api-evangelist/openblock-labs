# OpenBlock Labs (OB-1)

> OB-1 is a self-improving, autonomous coding agent that automates the software
> development lifecycle — from PM to PR. It runs in the terminal, VS Code, and
> JetBrains IDEs, consumes MCP servers for custom tools, supports 300+ models
> via OpenRouter with bring-your-own-keys, and integrates with GitHub, Linear,
> Graphite, and Slack. Billing is usage-based at 1:1 model-token pass-through.

This llms.txt was GENERATED by the API Evangelist enrichment pipeline from the
public OB-1 product surface and the published OAuth/OIDC metadata. OB-1 does not
publish a public OpenAPI, GitHub source, or package registry entry; the platform
API and manual sit behind authenticated dashboard access.

## Authentication
- OAuth 2.0 / OIDC authorization server: https://auth.openblocklabs.com
